# Політика безпеки

## Повідомлення про вразливість

Якщо ви знайшли вразливість у скриптах, конфігураціях або шаблонах цього репозиторію, не відкривайте публічне issue з деталями експлуатації. Повідомте про неї приватно через форму зв'язку на https://bcp.troshab.dev/#contact.

У повідомленні вкажіть:
- файл і рядок, де з'являється проблема;
- кроки відтворення та очікуваний ефект;
- коміт або дату завантаження репозиторію, яку ви використовували.

## Що вважається вразливістю

- обхід автентифікації або авторизації в компонентах стеку;
- виконання довільних команд через скрипти встановлення чи агенти;
- витік секретів або даних логів через конфігурацію за замовчуванням;
- небезпечні значення за замовчуванням у шаблонах, які можуть потрапити в продуктивне середовище без зміни.

## Секрети

Файл `.env`, ключі й паролі не входять до репозиторію. Значення для них генерує `server/gen-env.sh`. Не публікуйте секрети в issue, pull request або журналах.

## Лабораторні значення

Адреси, облікові записи й домен у прикладах призначені для навчального стенду. Їх не слід використовувати в реальній організації без заміни; опис стенду - у [docs/lab.md](docs/lab.md).
