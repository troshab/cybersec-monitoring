# Лабораторний стенд

Цей документ описує навчальний стенд, на якому курс перевіряє сценарії моніторингу й тестування. Він лише для навчального стенду і не є інструкцією для продуктивного середовища.

Адреси й облікові записи нижче належать лабораторній мережі 10.0.1.0/24 і домену LAB (lab.local). Паролі в репозиторії не зберігаються; для кожного облікового запису використовуйте менеджер паролів.

| Хост | IP | ОС | Облікові дані |
|------|----|----|---------------|
| Сервер моніторингу | 10.0.1.2 | Debian 13 | власний обліковий запис, пароль з менеджера паролів |
| Контролер домену | 10.0.1.3 | Windows Server 2025 | LAB\<admin>, пароль з менеджера паролів |
| Клієнт Windows | 10.0.1.4 | Windows 11 | LAB\<user>, пароль з менеджера паролів |
| Kali Linux | 10.0.1.5 | Kali (поточний випуск) | змініть пароль за замовчуванням після встановлення |

**Домен:** LAB (lab.local)
